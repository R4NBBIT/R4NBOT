# 🐣 계란봇

계란이 필요한 기능들을 모아놓은 디스코드 봇이에요! 메시지 청소, 로스트아크 레이드 클리어 골드 조회, 레이드/종겜/정모 일정 관리(모집·참가신청·대기열·고정공격대), 점심 메뉴 추천 기능을 제공합니다.

## 🚀 초대 링크

👉 https://discord.com/oauth2/authorize?client_id=1489505005625933974&permissions=8&integration_type=0&scope=bot

봇을 서버에 초대한 뒤, 디스코드에 `/`를 입력하면 아래 명령어들이 자동완성으로 떠요. 전체 명령어 목록과 사용법은 언제든 `/도움`으로 확인할 수 있어요.

## 🎮 명령어 목록

### 🧹 청소

| 명령어 | 설명 | 권한 |
|---|---|---|
| `/청소 [개수]` | 현재 채널 메시지 삭제 (개수 생략 시 전체) | 관리자 |

### 💰 클리어 골드 (로스트아크)

| 명령어 | 설명 | 권한 |
|---|---|---|
| `/클골 <레이드> <난이도>` | 클리어 골드·입장레벨·파티 정원 조회 | 전체 |

- "싱글" 난이도는 혼자 도는 레이드라 `/클골`에는 나오지만 `/레이드` 모집 대상에서는 제외돼요.
- 레이드/난이도 조합과 금액은 계란이 `/레이드추가`·`/레이드수정`·`/레이드삭제`로 관리해요.
- 3막/종막 익스트림처럼 기간이 정해진 이벤트 레이드는 종료일이 지나면 목록에서 자동으로 사라져요.

### 🍽️ 점심 메뉴 추천

| 명령어 | 설명 | 권한 |
|---|---|---|
| `/점메추` | 메뉴 랜덤 추천 (🎲 리롤 버튼으로 다시 뽑기 가능) | 전체 |
| `/메뉴추가 <메뉴> [공통]` | 메뉴 추가. 기본은 이 서버에만 추가되고, 공통=예로 하면 모든 서버가 공유하는 공통 메뉴에 추가됨 | 전체 (공통 추가는 계란 전용) |
| `/메뉴삭제 <메뉴>` | 메뉴 삭제. 이 서버에서 추가한 메뉴면 그냥 삭제되고, 공통 메뉴면 실제로 지워지지 않고 이 서버에서만 안 보이게 됨 | 전체 |
| `/메뉴판` | 이 서버에서 보이는 전체 메뉴 목록 조회 | 전체 |

메뉴는 모든 서버가 공유하는 **공통 메뉴**와, 서버마다 따로 쌓이는 **서버 메뉴** 두 종류예요. `/점메추`, `/메뉴판`은 "공통 메뉴 − 이 서버에서 숨긴 것 + 이 서버가 추가한 것"을 합친 목록을 기준으로 동작해요.

### ⚔️ 레이드 일정

| 명령어 | 설명 | 권한 |
|---|---|---|
| `/레이드채널 <채널>` | 레이드 모집 게시물을 올릴 포럼 채널 지정 (서버당 1개) | 관리자 |
| `/레이드채널해제` | 레이드 채널 지정 해제 | 관리자 |
| `/레이드채널정보` | 현재 지정된 레이드 채널 확인 | 전체 |
| `/레이드 <제목>` | 날짜/시/분/레이드/난이도 입력 → 모집 게시물 생성 | 전체 |

- 레이드 선택지에는 등록된 조합 외에 **"기타"**도 고를 수 있어요 (정원 16인 고정, 입장레벨 제한 없음).
- 게시물에는 **참가신청 / 참가변경 / 참가취소 / 대기열 명단 / ⚙️ 관리** 버튼이 달려요.
  - 참가신청: 캐릭터 닉네임을 입력하면 레벨·직업을 자동 조회해서 등록해요. 딜러/서포터 겸용 직업만 역할을 직접 고를 수 있어요.
  - 자리가 다 차면 자동으로 대기열에 등록되고, 빈자리가 생기면 대기열 1순위가 자동으로 올라와요.
  - ⚙️ 관리(서버 관리자 또는 작성자만): 일정수정, 제목수정, 삭제, 강제참여/강제변경/강제취소 가능.
- 시작 10분 전에는 참가자 전원에게 알림이 가고, 시작 30분 후에는 게시물이 자동으로 마감(기록은 남고 더 이상 조작 불가)돼요.

#### 🔔 레이드 알림 구독

| 명령어 | 설명 | 권한 |
|---|---|---|
| `/레이드알림추가 <레이드> <난이도>` | 해당 조합 모집 게시물이 올라올 때 멘션받도록 구독 | 전체 |
| `/레이드알림삭제 <레이드> <난이도>` | 구독 해제 | 전체 |
| `/레이드알림목록` | 내가 구독 중인 목록 확인 (나만 보임) | 전체 |

원하는 레이드+난이도 조합만 각자 자유롭게 구독/해제할 수 있어요. "기타"는 구독 대상이 아니에요.

#### 🔁 고정공격대 (매주 자동 게시)

| 명령어 | 설명 | 권한 |
|---|---|---|
| `/고정공격대생성` | 요일/시/분/레이드/난이도 + 로스터(멤버) 등록 | 전체 |
| `/고정공격대목록` | 이 서버에 등록된 고정공격대 목록 조회 | 전체 |
| `/고정공격대관리 <고정공격대>` | 일정/로스터 관리 (실제 조작은 작성자 또는 관리자만) | 작성자/관리자(조작 시) |

등록해두면 매주 같은 요일·시간에 `/레이드`와 같은 모집 게시물이 자동으로 올라와요 (등록된 로스터가 있으면 반영돼요).

### 🎮 종합게임 모집

| 명령어 | 설명 | 권한 |
|---|---|---|
| `/종겜채널 <채널>` | 종겜 모집 게시물을 올릴 포럼 채널 지정 (서버당 1개) | 관리자 |

| `/종겜채널정보` | 현재 지정된 종겜 채널 확인 | 전체 |
